# Enterprise Adoption Plan

## Outcomes

1. Safer AI-assisted engineering throughput
2. Common repository standards across teams
3. Visible governance and telemetry for leaders

## Phases

1. **Discover** — inventory repos, CI maturity, ownership, AI tool sprawl
2. **Standardize** — templates, CODEOWNERS, required checks, secret scanning
3. **Pilot** — 5–10 repos with governed agent workflows
4. **Measure** — delivery + governance KPIs (see metrics framework)
5. **Scale** — platform team support, training, policy exceptions process
6. **Govern continuously** — quarterly control review, dependency and model risk reviews

## Operating model

Platform engineering owns shared controls; product teams own domain code; security owns policy exceptions for CRITICAL pathways.
