# Metrics Framework

Track both delivery and governance. Separate **simulated** productivity estimates from measured operational telemetry.

## Measured in this blueprint

- Task completion count / blocked count
- Completion latency
- Tool-call success vs blocked attempts
- Approvals granted / denied / pending
- Policy violations
- High-risk percentage
- Review test/security pass flags

## Simulated (explicitly labeled)

- Manual vs AI engineering minutes
- Minutes saved
- PR cycle time placeholder

These simulated values support executive conversations about measurement design. They are **not** experimentally validated productivity claims.
