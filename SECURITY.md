# Security Policy

## Supported Versions

This repository is a reference architecture / working prototype. Security fixes
are applied to the `main` branch only.

| Version | Supported |
| ------- | --------- |
| 0.x     | Yes       |

## Reporting a Vulnerability

Do **not** open a public issue for suspected vulnerabilities.

Email security reports to your organization's security contact (placeholder:
`security@example.com`) and include:

- Description of the issue
- Steps to reproduce
- Impact assessment
- Any suggested remediation

## Scope

This prototype demonstrates governance patterns. It is **not** a production
security boundary. See `docs/security-model.md` for limitations and enterprise
integration points.
